CRON JOB
--------
Runs collectAndPushData.py every 10 minutes.

View cron jobs:
  crontab -l

Edit cron jobs:
  crontab -e

Current entry:
  */10 * * * * cd /home/eedm/eedmLabDashboard && /home/eedm/sensor-env/bin/python collectAndPushData.py >> /home/eedm/cron.log 2>&1

Check recent output:
  tail ~/cron.log


If something breaks

401 error: Token expired or wrong — regenerate at github.com → Settings → Developer settings → Personal access tokens
409 error: SHA mismatch — script tried to update stale data; just retry
Page not updating: Check Actions tab for build errors; hard refresh browser (Cmd+Shift+R)
